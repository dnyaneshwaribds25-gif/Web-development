Frequently Asked Questions

1. What is HTML?
HTML stands for HyperText Markup Language. It is used to create the structure of webpages.
2. What is CSS?
CSS stands for Cascading Style Sheets. It is used to style and design webpages.
3. What is JavaScript?
JavaScript is a programming language used to make webpages interactive.
4. What is DOM?
DOM stands for Document Object Model. It allows JavaScript to access and modify HTML elements.
